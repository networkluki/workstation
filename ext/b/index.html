Usage Overlay for Gemini

Last updated: 2026-09-28

Usage Overlay for Gemini (“the extension”) is an unofficial, experimental browser extension for Chrome and Firefox that shows your Gemini app usage limits.

It is not affiliated with or endorsed by Google.

Summary

None
Data sent to third parties
None
Analytics, tracking, ads
None
Network requests
gemini.google.com only

01What the extension accesses

The extension only contacts https://gemini.google.com, using your existing Google session in the browser:

  • GET https://gemini.google.com/usage, the Gemini usage page. The extension reads three request values from the page (SNlM0e, cfb2h and FdrFJe) that the site requires for its usage request. The rest of the page, which may include account details such as your name or email address, is discarded immediately and never stored.
  • POST https://gemini.google.com/_/BardChatUi/data/batchexecute with the request id jSf9Qc, the same request the usage page makes. The extension reads the usage meters in the response: for each meter the limit value, the fraction used, the period (5-hour or weekly) and the reset time.

The extension does not read your conversations or any other page content on gemini.google.com. It does not read, store or transmit your cookies or password; your browser attaches its own session cookies to requests to gemini.google.com.

02Request values

The values read from the usage page are held in memory only for the duration of one refresh. They are used only in the usage request to gemini.google.com, and are never stored, logged, displayed or sent anywhere else.

03How the data is used

Only to show your usage in the toolbar badge, the popup and the overlay on gemini.google.com. The popup also shows the raw meter values as diagnostics, so the percentages can be checked against the Gemini usage page.

04Where the data is stored

The latest usage figures (percentages, reset times and the raw meter values shown as diagnostics) and your settings (overlay, background, position, badge and refresh interval) are stored locally in your browser’s extension storage. The figures are replaced on each refresh, and all stored data is removed when you uninstall the extension.

05Sharing

The extension sends no data to the developer or to any third party. It contains no analytics, tracking or advertising and uses no servers of its own. Its only network requests go to gemini.google.com, as described above.

06Permissions

The use of information received from gemini.google.com adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
