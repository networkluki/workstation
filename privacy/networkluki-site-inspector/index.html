NetworkLuki Site Inspector Privacy Policy

This privacy policy explains what data the Chrome extension handles, how it is used, and why no user data is collected, sold, shared, or transferred by NetworkLuki.

Effective date: 2026-05-11

Short summary

NetworkLuki Site Inspector is designed to inspect the currently active browser tab and show basic browser-observed site information such as URL, origin, hostname, protocol, HTTPS status, and simple security signals.

  • No account is required.
  • No analytics, ads, trackers, or third-party scripts are used.
  • No personal data is sold or shared.
  • No page content, form fields, passwords, cookies, or browsing history are collected.
  • The extension does not transmit inspection data to NetworkLuki servers in this version.

Data collection

NetworkLuki does not collect user data through this extension. The extension works locally in the user's browser and only processes the active tab after the user opens the extension.

The active tab URL may be read locally to display technical information to the user. This information is not sent to NetworkLuki or to any third party.

Data use

The extension uses active-tab information only for its single purpose: showing a local site inspection report for the page the user is currently viewing.

The extension does not use data for advertising, profiling, credit decisions, unrelated analytics, or user tracking.

Data sharing

NetworkLuki does not sell, rent, transfer, or share user data collected through this extension because the extension does not collect such data.

No inspection data is transmitted to external servers in this version.

Local storage

If the extension version uses Chrome local storage, it is used only to keep the latest inspection report locally inside the user's browser.

Locally stored data is not transmitted to NetworkLuki or third parties. Users can remove extension data by removing the extension or clearing browser extension storage.

Permissions

The extension may request the following Chrome permissions:

  • activeTab: used only when the user clicks the extension icon, so the extension can inspect the currently active tab URL and show the report.
  • storage: used only if the extension keeps the latest inspection report locally in the browser. It is not used for external collection or tracking.

Changes to this policy

This privacy policy may be updated if the extension changes. If future versions add server-side DNS checks, HTTP header checks, analytics, accounts, or any data transfer, this policy and the Chrome Web Store data disclosures must be updated before release.
