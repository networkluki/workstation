ipconfig.se IP & Site Inspector Privacy Policy

Effective date: 2026-05-11

Summary

This extension lets users view their public IP address and inspect the currently active site using ipconfig.se resolver endpoints.

The extension does not use ads, analytics, third-party trackers, accounts, or extension-side user profiling. It does not read page content, form fields, cookies, passwords, or personal communications.

Data processed

  • Public IP lookup: ipconfig.se receives the user's public IP as part of the request to /ip.json.
  • DNS lookup: the active site's hostname is sent to /dns.json when the user runs external checks.
  • External HEAD check: the active site's origin, such as https://example.com, is sent to /headers.json. The extension does not send the full page path or query string.

What is not collected

  • No page text, images, videos, DOM content, form fields, cookies, passwords, authentication tokens, private messages, or personal communications are read.
  • No click tracking, mouse tracking, keystroke logging, behavioral analytics, ads, or credit-decision use occurs.
  • No Chrome local storage is used in this extension version.

Data sharing

The extension communicates only with ipconfig.se endpoints needed for its single purpose. Data is not sold or shared with third-party advertising, analytics, or profiling services.

Standard server infrastructure may process HTTP requests to operate the service and protect against abuse.

Permissions

  • activeTab: used when the user opens the extension to read the current tab URL, host, and HTTPS status.
  • https://ipconfig.se/*: used to call ipconfig.se IP, DNS, and header endpoints.
