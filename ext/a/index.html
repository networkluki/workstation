Privacy Policy

Usage Overlay for Codex

Last updated: 2026-09-28

Usage Overlay for Codex (“the extension”) is an unofficial browser extension for Chrome and Firefox that shows the Codex usage limits of your ChatGPT plan.

It is not affiliated with or endorsed by OpenAI.

01What the extension accesses

The extension only contacts https://chatgpt.com, using your existing chatgpt.com session in the browser:

  • GET https://chatgpt.com/api/auth/session. The response contains your session’s access token and account details such as your name and email address. The extension reads only the access token; everything else in the response is discarded immediately and never stored.
  • GET https://chatgpt.com/backend-api/wham/usage, sent with that access token. The extension reads your usage percentages, the length and reset time of each limit window, the names of model-specific limits and, if your account has credits, the credits balance. Other fields in the response (for example plan type, account and user identifiers) are ignored and not stored.

The extension does not read your conversations, prompts, code or any other page content on chatgpt.com. It does not read, store or transmit your cookies or password; your browser attaches its own session cookie to requests to chatgpt.com.

02Access token

The access token is held in memory only for the duration of one refresh. It is used only in the Authorization header of the usage request to chatgpt.com, and is never stored, logged, displayed or sent anywhere else.

03How the data is used

Only to show your usage in the toolbar badge, the popup and the overlay on chatgpt.com.

04Where the data is stored

The latest usage figures (percentages, reset times, model-specific limit names and the credits balance) and your settings (overlay, background, position, badge and refresh interval) are stored locally in your browser’s extension storage. The figures are replaced on each refresh, and all stored data is removed when you uninstall the extension.

05Sharing

The extension sends no data to the developer or to any third party. It contains no analytics, tracking or advertising and uses no servers of its own. Its only network requests go to chatgpt.com, as described above.
